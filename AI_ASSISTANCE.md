# AI-Assisted Development Disclosure

Adamastus was developed with assistance from **ChatGPT (OpenAI)**, using the
**GPT-6** model.

## How AI assistance was used

ChatGPT was used as a development assistant during the design and implementation
of the project. Its assistance included:

- discussing the project structure and implementation approaches;
- drafting, explaining, reviewing and refactoring Python code;
- helping develop and review database, data-download and analysis workflows;
- helping create and refine automated tests and investigate potential bugs;
- drafting and improving project documentation;
- reviewing the repository for consistency, usability and deployment readiness.

The project was developed iteratively. Suggestions and generated material were
considered, adapted and incorporated as part of the development process; this
disclosure does not imply that every line of code was generated by AI.

## Human responsibility

The project maintainer provides the project direction, requirements and domain
context, makes the final implementation decisions, and is responsible for
reviewing, testing, maintaining and releasing the project. AI-generated or
AI-suggested material can contain errors and should not be treated as verified
solely because it was produced or reviewed by an AI tool.

This disclosure is intended to make the use of AI assistance transparent. It is
not a claim of AI authorship, a statement about the proportion of code generated
by AI, or a substitute for the project's software licence and data-source terms.

## Scope and updates

This statement describes the development process to date. It should be updated
if additional AI tools are used in a material way or if the nature of their
contribution changes significantly.
